Documentation

Guide d'utilisation des commandes CRYNYX sous Windows.

Commandes disponibles

crypt

Chiffre un fichier avec une clé XOR.

crypt <fichier> [-key <mot_de_passe>]
  • fichier : nom du fichier à chiffrer
  • -key : (optionnel) clé de chiffrement. Si absente, une saisie masquée est demandée.

Exemple :

crypt document.txt -key 1234

decrypt

Déchiffre un fichier .enc.

decrypt <fichier.enc> [-key <mot_de_passe>]
  • fichier.enc : fichier chiffré
  • -key : (optionnel) clé de déchiffrement. Si absente, une saisie masquée est demandée.

Exemple :

decrypt document.txt.enc -key 1234

cd

Change le répertoire courant.

cd <chemin>

Exemple :

cd C:\Users\Public\Documents

pwd

Affiche le chemin du répertoire courant.

pwd

help

Affiche la liste des commandes disponibles.

help

crynyx --version

Affiche la version de CRYNYX.

crynyx --version

Fonctionnement du chiffrement

CRYNYX utilise un chiffrement XOR symétrique. La même clé est utilisée pour chiffrer et déchiffrer.

  • Avantage : simplicité, rapidité, aucun fichier intermédiaire.
  • Limite : le XOR est un chiffrement faible. À réserver à un usage personnel.

Conseil : utilisez une clé d'au moins 16 caractères pour renforcer la sécurité.

Types de fichiers supportés

CRYNYX lit et écrit en mode binaire. Il peut donc chiffrer tout type de fichier :

  • Textes (.txt, .csv, .log)
  • Images (.png, .jpg, .bmp, .gif)
  • Documents (.pdf, .docx, .xlsx, .odt)
  • Archives (.zip, .rar, .7z)
  • Exécutables et autres fichiers binaires

Saisie des clés sans affichage

Si vous ne passez pas la clé avec l'option -key, CRYNYX vous la demande de manière masquée (les caractères sont remplacés par des *).

Important : les fichiers .enc contiennent le résultat du XOR avec votre clé. Conservez votre clé précieusement, elle est nécessaire pour déchiffrer.

Historique des commandes

CRYNYX conserve un historique des commandes saisies pendant la session. Il n'y a pas encore de persistance entre les sessions sous Windows.
