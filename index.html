CRYNYX

Un shell léger pour chiffrer vos fichiers

Chiffrement XOR - Open Source - Multiplateforme

Télécharger Documentation
CRYNYX > crypt document.txt -key 1234
document.txt → document.txt.enc (successfully encrypted)

CRYNYX > decrypt document.txt.enc -key 1234
document.txt.enc → document.txt (successfully decrypted)

Pourquoi CRYNYX ?

XOR

Chiffrement symétrique

Chiffrez et déchiffrez vos fichiers avec une clé personnalisée ou par défaut.

BIN

Lecture binaire

CRYNYX traite tous les types de fichiers : textes, images, PDF, archives, etc.

C

Écrit en C

Léger, rapide, sans dépendances lourdes. Un exécutable unique.

OS

Linux et Windows

Disponible pour Linux, WSL et Windows (exécutable .exe inclus).
