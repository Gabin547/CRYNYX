Avertissement Windows Defender / SmartScreen

Lorsque vous lancez CRYNYX, Windows peut afficher un message : "Windows protected your PC" ou "Virus detected".

Ce message est normal. Il apparaît parce que CRYNYX est un logiciel non signé numériquement et encore peu connu de Microsoft. CRYNYX n'est pas un virus. Le code source est entièrement visible sur GitHub.

Comment lancer CRYNYX

  1. Téléchargez le fichier crynyx.zip
  2. Extrayez le fichier crynyx.exe du dossier zip
  3. Double-cliquez sur crynyx.exe
  4. Si le message "Windows protected your PC" apparaît :
    • Cliquez sur "More info" (Plus d'infos)
    • Puis cliquez sur "Run anyway" (Exécuter quand même)
CRYNYX > crypt document.txt
✅ document.txt → document.txt.enc (successfully encrypted!)

Transparence : Si vous préférez, vous pouvez compiler vous-même le code source depuis GitHub.

Guide d'installation

  1. Téléchargez crynyx.zip ci-dessus
  2. Extrayez crynyx.exe du dossier zip
  3. Placez-le dans le dossier de votre choix
  4. Ouvrez l'invite de commandes (cmd) ou PowerShell
  5. Exécutez :
crynyx.exe

Vous pouvez aussi double-cliquer sur crynyx.exe pour lancer le shell.
